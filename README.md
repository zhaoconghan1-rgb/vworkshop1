# 木丛

按地区认识树木的前端网站。React + TypeScript + Vite + Tailwind CSS，纯静态部署，无登录、数据库或网页内容管理。

## 当前查看

本次交付的构建预览：http://127.0.0.1:4173/ 。本地预览需要服务保持运行；旧的 5173 页面可能是早期绿色版本，请使用 4173。

试用：亚洲 → 白桦 → 点击秋或冬 → 查看照片待补充状态 → 刷新（季节保持）→ 返回亚洲 → 切换欧洲 → 打开夏栎 → 浏览器返回。

## 启动与构建

推荐 Node.js 22 或更高版本、pnpm 11。以下命令在本工程目录执行，由 AI 或协作者处理即可：

```sh
pnpm install --frozen-lockfile
pnpm dev --port 5174 --strictPort
pnpm typecheck
pnpm build
pnpm preview --port 4173 --strictPort
```

开发服务会显示本地地址。若预览已在运行，无需再启动同一端口。构建结果在 `dist/`，`pnpm build` 已包含 TypeScript 检查。项目锁定依赖在 `pnpm-lock.yaml`，允许的 esbuild 安装脚本写在 `pnpm-workspace.yaml`。

## 内容与素材

- `src/data/trees.ts`：20 个树木示例，亚洲 10 个；地区、介绍、季节说明及图片引用集中维护。
- `public/images/`：已下载的 4 张 Stitch 白桦示例图。构建会复制到 `dist/images/`，不依赖图片外链。
- `src/data/image-sources.json`：原图来源和示例状态；不是组件运行依赖。
- `src/main.tsx`：地区浏览、详情、照片组件与界面状态。
- `src/index.css`：统一配色和字体规则。最新采用白底、黑字、灰色辅助层次，取代先前绿色方案。

实际内容仍不完整：白桦介绍来自导出材料的简化示例，待植物学核实；春季大图仅为示例，夏秋冬照片缺失。其余 19 项的选树及地区关联为示例，介绍与图片待补充。地区文化资料尚待提供。没有把生成图当作实拍，也没有编造精确观测地点、日期或观测站记录。

更新流程：用户提供照片和文字 → AI 写入上述内容文件及图片目录 → 本地预览检查 → 用户手动发布。每个树种的 `photos` 支持春夏秋冬独立图片，缺失时显示待补充。细节图不随季节伪变换。页面使用哈希地址保存当前地区、树种、季节，刷新可恢复；不使用浏览器存储保存正式内容。

字体优先使用本机宋体类标题（Songti SC / STSong / Noto Serif SC）与黑体类正文。不同系统回退字形可能略有不同；无在线字体依赖。

## Vercel 手动部署

AI 未执行上线、推送或发布。

1. 由你把此工程加入自己的代码仓库，或交给协作者准备；不提交 `node_modules`、凭证和 `.env`。
2. 在 Vercel 新建项目，选择自己的仓库。如果仓库包含多个目录，Root Directory 选本工程目录。
3. 框架选择 Vite；安装使用 `pnpm install --frozen-lockfile`；构建使用 `pnpm build`；输出目录为 `dist`。本项目不需要环境变量。
4. 由你点击 Deploy。以后更新也由你选择版本并手动发布；如接入仓库，请关闭或避免自动推送部署。
5. 发布后打开首页和树木详情，刷新并检查图片。提供线上地址后可再检查，当前不宣称线上已验证。

`vercel.json` 已指定 Vite 和 dist。网站采用哈希路由，不需要服务端重写。仅 `dist/` 是公开产物；AGENTS.md、项目记录、README 和参考设计不放在 public 目录，也不包含在 dist 中。
